# A — 82 selected static designs

This contribution contains the frozen initial41 designs and subsequent41 through the integrated hydraulic ironworker: 738 model files, three decreasing LODs in BLEND/GLB/FBX per design. Assets and approved representative renders are under `assets/<ID>/`. CATALOG.json records selected revisions, file hashes and item-specific limitations.

No source photographs/manuals, generator code, private QA notes, failed candidates or superseded revisions are included. Model materials require no external image resources according to retained selection evidence. These are static visual assets, not operational equipment or certified safety/medical/Unity implementations. Dimensions and hidden details may be generic approximations as documented.

SHA256SUMS.txt verifies every file in A except itself; run `sha256sum -c SHA256SUMS.txt` from this A directory. Original local candidates and earlier delivery snapshots are preserved.
