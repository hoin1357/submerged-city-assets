# 꽃 화환 — B114

꽃·잎·리본과 뒷면 지지를 포함한 정적 장식 한 개입니다. 특정 행사나 꽃의 생물종을 재현한 제품은 아닙니다. 보이지 않는 뒷면 지지와 연결은 일반화했습니다. 별도 받침대는 없습니다.

- BLEND·FBX·GLB 각 LOD0/1/2, 총 9개 모델. 삼각형 수: 93,424 / 40,572 / 17,972.
- 자체 근사 비례, 미터 단위. Blender는 Z 위쪽이며 화환의 주 평면은 XY입니다. FBX/GLB는 포맷의 축 변환을 사용하며 Blender 재수입으로 형상을 확인했습니다.
- 꽃잎·잎·리본은 한 조립체의 구성품입니다. 꽃잎과 꽃 띠의 일부 겹침은 장식 조립을 위한 의도된 연결입니다.
- 단순 색상 재질 5개. 외부 이미지·텍스처·글꼴 의존성 없음. UV는 삼각형별 기본 좌표이며 통합 라이트맵 아틀라스가 아닙니다.
- 축소 무라벨 렌더에서 꽃 장식과 빈 중심을 확인했습니다. 이용자 식별성 실험 결과는 아닙니다. LOD2는 근접 시 각진 꽃잎이 보입니다.
- 애니메이션·변형·물리 기능 없음. 실제 설치·하중·안전 또는 Unity 인증을 주장하지 않습니다.
