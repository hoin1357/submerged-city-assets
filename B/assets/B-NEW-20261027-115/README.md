# B115 일반 파티 가면

한 개의 완성된 정적 소품입니다. 두 개의 실제 눈구멍, 얇은 얼굴 쉘, 길게 돌출된 코와 연결된 뒤끈을 포함합니다. 특정 전통·캐릭터·브랜드를 주장하지 않습니다.

BLEND·FBX·GLB 각각 LOD0/1/2를 제공합니다. 삼각형은 16,416 / 7,904 / 2,804개이며 모두 동일한 한 종류의 감축본입니다. 모델 좌표는 미터 단위, Z-up이며 실제 제품의 측정 치수나 착용 맞춤을 보증하지 않습니다.

단일 참고 시점에서 보이지 않는 안쪽과 뒤끈은 일반화했습니다. 쉘은 약 1.6mm 두께이며 뒤끈과 양옆 접합부는 하나의 폐쇄 메시로 연결했습니다. 별도 부품의 관통 겹침을 사용하지 않습니다. 보호·의료·착용 기능, 애니메이션이나 물리 시뮬레이션은 제공하지 않습니다.

단순 재질 2개, 외부 텍스처·폰트 의존성 없음. 각 메시의 UV는 삼각형별 겹치지 않는 유틸리티 배치이며 도색용 연속 UV 아틀라스는 아닙니다. 감축본에서도 눈구멍을 유지합니다. Blender에서 9개 모델 재수입 및 실제 렌더를 검수했으며, 128px 식별성은 제작자 판단으로 사용자 실험은 아닙니다. Unity 등 대상 엔진 직접 검증은 하지 않았습니다.

FBX 제작 앱의 원본 파일명 메타데이터는 중립 상대파일명으로 정리했습니다. 해당 문자열 외 노드·속성·기하·재질·UV·노멀 데이터는 내보내기 원본과 동일합니다. 참고 사진 및 중간 실패본은 포함하지 않습니다.

재수입 한계: 원본과 비교한 GLB 코너 노멀의 최대 각도 차이는 약 0.735°였고 FBX는 해당 검사에서 0°였습니다. 최대 정점 위치 오차는 약 2.69×10⁻⁸m입니다. 실제 렌더에서 식별 가능한 접합·외형 오류는 발견하지 않았으나 모든 엔진에서 완전히 같은 셰이딩을 보증하지 않습니다.

공개용 메타데이터 정리: BLEND의 파일 선택 기본 디렉터리와 렌더 출력 경로만 상대경로로 바꾸고, PNG의 제작 파일명 텍스트만 제거했습니다. 나머지 BLEND 구조·메시·UV·재질·노멀·애니메이션 데이터와 PNG 픽셀은 원본과 동일합니다. 원본 선택본은 별도 보존합니다.
