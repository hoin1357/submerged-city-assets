# B116 일반 열기구 — 정적 소품

큰 주름 기낭, 열린 목, 네 현수 지지와 속이 빈 탑승 바구니를 포함한 한 개의 전체 열기구입니다. 바구니·로프·기낭을 별도 종류로 세지 않습니다. 기존 바구니나 풍선 모델을 추출하지 않고 새로 구성했습니다.

3LOD × BLEND/FBX/GLB = 9모델. 삼각형은 23,916 / 11,092 / 5,220개입니다. 미터 단위·Z-up, 크기는 게임용 일반화이며 참고 사진의 측정 치수가 아닙니다. 특정 기종·브랜드를 주장하지 않습니다.

참고는 225×300 단일 사진입니다. 원촬영자와 개별 사진의 재배포 권리는 확인되지 않았습니다. 참고 사진·체크무늬 텍스처·배경 사람·차·작은 열기구는 이 납품에 포함하지 않습니다. 숨은 안쪽과 현수 체결 구조는 일반화했으며 바구니 벽은 단순화했습니다. 버너·열·비행·탑승 기능 및 안전 성능을 구현하거나 보증하지 않습니다.

기낭은 약 5mm의 방사 방향 두께를 가진 쉘이며 아래 목은 열려 있습니다. 바구니는 열린 입구, 약 25mm 벽과 바닥이 있습니다. 모두 정적 외형용 수치입니다. 네 지지와 쉘/바구니 접합을 단일 폐쇄 메시로 연결하여 별도 부품의 관통 겹침을 남기지 않았습니다.

단순 재질 4개, 외부 이미지·폰트 의존성 없음. UV는 삼각형별 겹치지 않는 유틸리티 배치이며 연속 도색용 아틀라스는 아닙니다. GLB의 UV/재질 경계 분리 정점은 1µm 허용오차의 가상 용접으로 연결성을 검사했습니다. 재수입 최대 위치 오차 약 0.698µm, 코너 노멀 각도 차이 약 0.074°입니다. 대상 게임 엔진은 직접 검증하지 않았습니다.

9모델 재수입과 실제 전체·근접 렌더 및 128px 식별성을 검수했습니다. 식별성은 제작자 판단이며 사용자 실험이 아닙니다. FBX 제작 위치 메타데이터만 중립 상대파일명으로 정리했으며 해당 필드 외 모든 바이트는 원본과 같습니다.

공개용 메타데이터 정리: BLEND의 파일 선택 기본 디렉터리와 렌더 출력 경로만 상대경로로 바꾸고, PNG의 제작 파일명 텍스트만 제거했습니다. 나머지 BLEND 구조·메시·UV·재질·노멀·애니메이션 데이터와 PNG 픽셀은 원본과 동일합니다. 원본 선택본은 별도 보존합니다.
