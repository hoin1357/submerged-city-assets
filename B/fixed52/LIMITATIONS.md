# Scope and limitations

Original unbranded static game props, not certified reproductions or functioning equipment. No medical, electrical, optical, food-contact, load, safety or Unity runtime certification. Unobserved internals and some dimensions are generic approximations. Consult per-asset notes in CATALOG.json.

Native/GLB/FBX reimport checks and existing renders were reviewed during production. Transparent materials, reflections and shading can differ by format or runtime; these files are not proof of identical rendering in every engine.

Raw GLB UV evidence now covers all156GLBs. Missing UV, nonfinite values and UV collapse on positive-area geometry were not found.19designs/28GLBs have small negative UV boundary excursions, minimum -7.469207048416138e-7; these were reported separately and were not modified.

Only the latest selected revision is included. Failed trials, old revisions, backups, diagnostic reports, manufacturer references, private records and credentials are excluded. B067 remains unbuilt pending an observed reference and is not included. Previously delivered B001–B012 are outside this resumed batch.
