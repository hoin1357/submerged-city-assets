# B101 — Static ascending escalator module

선택본: B-NEW-20261026-101 / R3. 한 정적 소품 또는 소품 세트입니다.

제공 파일: LOD0·LOD1·LOD2 각각 BLEND·GLB·FBX, 총 9개. 삼각형 수는 순서대로 65840 / 24368 / 10192입니다. LOD는 대체 표현이므로 동시에 겹쳐 배치하지 마세요.

크기: 제작 좌표계의 X×Y×Z 경계 1.2200 × 4.9200 × 2.9700 m. 실측 제품 치수가 아닌 자체 비례입니다. 미터 단위 경계는 기존 영수증 기준이며, 형식별 축 변환·대상 앱의 가져오기 설정은 별도 인증되지 않았습니다. 가져온 뒤 크기와 방향을 확인하세요.

진입부·경사진 계단·손잡이 반환부를 가진 건축 모듈입니다. 상부 연결과 밑면은 일반 근사이며 전체 건물이나 구동 설비는 없습니다. 유리는 단순 알파 재질입니다.

자체 재질을 사용합니다. 기존 의존성 검사에서 외부 이미지·라이브러리·폰트 및 FBX 리소스 경로 참조가 없었습니다. 다른 렌더러에서 동일한 반사·투명 표현을 보장하지 않습니다.

기존 검수에는 세 LOD의 형식 재수입·UV·접합·겹침 점검과 48개 실제 렌더 확인이 포함됩니다. 이는 정적 외형 검수이며 실제 작동·성능·안전 또는 Unity 인증을 의미하지 않습니다.
