# 214 static asset designs — unpacked delivery

This branch contains 214 designs and 1,926 model files: three LODs in BLEND, FBX and GLB for each design. LODs and format copies are not additional designs.

- `A/`: 82 designs.
- `ROOT/`: 35 designs, restored from the upload mapping.
- `B/fixed52/`, `B/incremental/`, `B/additions/`: 97 designs.

Files are provided directly in folders, without ZIP archives. Representative renders and asset-specific user documentation accompany the models. Read those documents for dimensions, material handling and individual limitations.

These are static visual assets. Functional mechanisms, engineering accuracy, load capacity, medical/electrical/fire safety and Unity runtime certification are not promised. Source reference photographs, private work notes and failed revisions are excluded.

`DELIVERY_MANIFEST.json` lists the 2,630 contribution files with sizes and SHA256 hashes. `ROOT_FILE_MAPPING.json` retains upload provenance; its target paths are the final locations. These two metadata files and this README are additional to the contribution payload.
