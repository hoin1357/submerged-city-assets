# ROOT080 — 전개된 캐노피 구명뗏목

원본 무브랜드 정적 조립품 1종입니다. 비압축 개별 파일: 편집 가능한 BLEND와 FBX/GLB 각 3LOD, 실제 대표 렌더 3개, 사용자용 문서와 체크섬. 추가 검사 이미지 11개는 로컬에 보존하고 전달본에서는 제외했습니다.

삼각형 9,940 / 4,572 / 2,628. 이중 부력 튜브 형태, 길게 솟은 캐노피, 닫힌 앞 덮개, 반사색 패치, 밸브 캡, 제한된 웨빙과 짧은 줄을 갖춘 정적 외형입니다. 실제 제조사 치수가 아닌 자체 근사 크기이며 숫자는 QA_AND_LIMITS.json에 기록했습니다.

해양 대여 웹사이트 공개 저장소의 실제 사진을 직접 보고 참고했습니다. 파일명은 Crewsaver를 가리키지만 정확한 모델·촬영자·사진 라이선스를 독립 인증하지 않았습니다. 사진/로고/정원 표시를 복사하거나 전달물에 넣지 않았습니다. 수면에 가려진 바닥과 내부는 확인하지 못했으므로 닫힌 바닥 마감과 뒷면 이음선은 원본 일반화입니다. 열린 내부·진입 경사판·밸러스트 기능을 주장하지 않습니다.

실제 부력·팽창·항해·구조·하중·리그·안전·콜라이더·Unity 실행 인증이 없는 게임 소품입니다. 각 LOD의 접합/UV/재질/6회 재수입/원시 UV/외부 의존성을 검사했지만 포맷별 픽셀·음영 일치나 실제 구명장비 성능을 의미하지 않습니다.

실제 40샘플 비디노이즈 검사 렌더에는 캐노피 넓은 면의 일부 밝은 점과 샘플링 노이즈가 남습니다. 이를 천 텍스처/시뮬레이션으로 주장하지 않습니다.
