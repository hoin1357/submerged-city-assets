# ROOT081 — 열린 뚜껑 제빵기

원본 무브랜드 정적 조립품1종입니다. BLEND/FBX/GLB의 실제3LOD 총9개, 네이티브/GLB/FBX 대표 실제 렌더3개를 제공합니다. BLEND는 편집 가능한 원본입니다. 추가 QA 렌더11개는 로컬에 보존하고 이 비압축 개별 파일 전달본에는 넣지 않았습니다.

삼각형 14,460 / 8,928 / 5,108. 자체 근사 크기는0.380×0.306×0.568m이며 제조사 실측 치수가 아닙니다. 실제 팬 내부와 두 고정 반죽날, 철사 손잡이, 오른쪽 조작부, 세워진 뚜껑/타원창/그립/환기 외형을 모델링했습니다. 설명도의 단면 절개를 실제 케이스 구멍으로 만들지 않았습니다.

참고는2006 B2300설명서의 기술 도해이며 사진이 아닙니다. 요리 작성자의 공개 저장소에 있는 원본 형식 문서로 식별은 일관되지만 진위는 독립 인증하지 않았습니다. 참고 PDF/그림/브랜드를 패키지에 넣거나 텍스처로 복사하지 않았습니다.

타원창은 불투명 스모크색의 정적 표현입니다. 내부 히터/전자장치/전원선/계량도구는 없습니다. 숨은 접합과 후면 블라인드 입력부는 일반화된 원본 해석입니다. 실제 가열·제빵·반죽·식품접촉·전기안전·하중·리그·콜라이더·Unity 실행 인증이 없으며 포맷 사이 픽셀/음영 동일성도 보장하지 않습니다.

기하/UV/재질/6회 재수입 및 원시 UV/외부 의존성 검사를 통과했습니다. 자세한 범위와 노멀 차이는 QA_AND_LIMITS.json을 참조하십시오.

전달 방식은 비압축 개별 파일입니다. FBX에서는 원본/GLB보다 하우징 조명이 더 각지게 보입니다. 원시 노멀·기하·UV·PBR 검증 통과와 포맷별 렌더 음영 동일성은 별개입니다.
