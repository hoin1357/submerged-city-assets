# ROOT096 — 타이어 탈착기

무브랜드 원본 정적 전체 기계 1종입니다. 비압축 BLEND/FBX/GLB 각 3LOD, 실제 대표 렌더 3개, 사용자 문서·체크섬을 포함합니다. 추가 검사 뷰 11개는 로컬에 보존합니다.

삼각형 22,104 / 10,312 / 5,176. 앞쪽 네 발판·캐비닛·바닥 지지대, 휠 리프트 레일과 부착 크래들, 중앙 클램핑 축·작은 턴테이블, 후방 기둥과 상부 마운팅 암·공구 머리, 위아래 보조 롤러, 조작부·빈 표시창·게이지, 뒤쪽 모터·유체통·닫힌 전기함·공기탱크·호스를 포함합니다. 타이어/림 작업물은 제외했습니다. 탱크·리프트·공구를 따로 세지 않습니다.

공급사 Auto Body Toolmart가 호스팅한 Ranger RX3040 제조사 발행 설명서(Rev A 04-13-10, PN5900375)의 표지·8/9쪽 실제 다각도 제품 도판을 직접 확인했습니다. 출판 이미지의 사진/렌더 제작 방식은 별도 인증하지 않았습니다. 자체 근사 비례·크기이며 제조사 실측 치수 재현이 아닙니다. 제조사 그림·PDF·상표·사진 텍스처·내부 메모는 포함하지 않습니다.

보이지 않는 구동부·유압/공압 경로·전기 구성과 공구의 정밀 형상은 일반화한 외관입니다. 실제 타이어 작업·유압/공압·전기·하중·안전·리그·콜라이더·Unity 인증은 없습니다. 6회 재수입 검사는 모든 포맷의 동일 음영을 보장하지 않습니다.

실제 Cycles 40샘플 무디노이즈 렌더에 샘플 노이즈가 남습니다. 낮은 LOD의 호스·원형 부품·베벨은 근접 시 각진 면이 보일 수 있습니다. 세부 검사 뷰 일부는 다른 부분을 의도적으로 자릅니다.
