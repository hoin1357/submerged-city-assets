# ROOT101 — 반팔 티셔츠

무브랜드 원본 정적 반팔 상의 한 벌입니다. 비압축 BLEND/FBX/GLB 각3LOD, 실제 대표 렌더3개, 사용자 문서·체크섬을 포함합니다. 추가 최종 검사뷰11개와128px 식별성 검사는 로컬에 보존합니다.

삼각형 40,928 / 23,408 / 10,752. 목·두 소매·밑단의 실제 개구부, 연속된 천 셸, 얕은 기하 주름과 단 처리를 갖습니다. 색상·핏·소매를 별도 종류로 세지 않습니다. 천 두께 설정은1.2mm이며 표본의 반대층 최단거리는 약1.106–1.967mm로 변합니다. 실제 균일한 원단 두께를 보증하지 않습니다.

고정 커밋의 공개 연구 저장소에 있는 BOSS 티셔츠 전체 도판을 직접 확인했습니다. 원 촬영자·제조사·정확 치수는 확인하지 않았으며 보이지 않는 뒤쪽은 일반화했습니다. 자체 근사 비례로 만든 단순화된 펼친 정적 소품입니다. 그림·라벨·상표·사진 텍스처·참고 원본은 포함하지 않습니다.

라벨 없는 실제128px 렌더를 검토자가 직접 보고 목파임·짧은 양 소매·몸통·밑단으로 티셔츠가 즉시 식별되는지 별도 확인했습니다. 관객 시험이나 사용자 전원에 대한 보증은 아닙니다.

착용 적합성·리그·천 시뮬레이션·정밀 직조·콜라이더·Unity 인증은 없습니다. 실제 Cycles40샘플 무디노이즈 렌더에 약간의 노이즈가 남고 낮은LOD의 곡면·단은 더 단순합니다.6회 재수입 검사는 모든 엔진의 동일 음영을 보장하지 않습니다.
