# ROOT102 — 비니 모자

무브랜드 원본 정적 전체 모자 한 개입니다. 비압축 BLEND/FBX/GLB 각3LOD, 실제 대표 렌더3개, 사용자 문서·체크섬을 포함합니다. 추가 최종 검사뷰11개와128px 식별성 이미지는 로컬에 보존합니다.

삼각형 17,408 / 7,680 / 3,456. 둥근 닫힌 윗부분, 접힌 커프를 표현한 두꺼운 아래쪽 외형, 실제 열린 밑면과 빈 머리 공간을 갖습니다. 얕은 원본 리브와 단순 올리브색 재질을 사용합니다. 니트·색상·줄무늬·크기를 별도 신규 종류로 세지 않습니다.

고정 커밋 공개 연구 저장소의 BOSS 모자 전체 도판을 직접 확인했습니다. 원 촬영자·제조사·정확 치수는 미확인입니다. 보이지 않는 내부·뒷면과 비례는 일반화했습니다. 접힌 커프 내부의 실제 직조층을 정확히 복원한 것은 아닙니다. 참고사진·라벨·상표·무늬·사진 텍스처는 포함하지 않습니다.

표본 반지름 방향 재질 구간은 약3.410–22.548mm이며 아래 커프가 두껍습니다. 이는 균일한 표면 법선 방향 원단 두께나 실제 물성을 보증하지 않습니다. 밑면에서 내부로 통하는 공간과 닫힌 윗부분을 메시·레이로 별도 검사했습니다.

실제128px 무라벨 렌더를 검토자가 직접 보고 둥근 윗부분과 접힌 하단으로 비니/털모자가 바로 읽히는지 확인했습니다. 관객시험이나 전체 사용자에 대한 보증은 아닙니다. 착용·천물리·정밀 직조·리그·콜라이더·안전·Unity 인증은 없습니다.

낮은LOD의 곡면은 더 단순하고 무디노이즈 Cycles40샘플 렌더에 약간의 노이즈가 남습니다.6회 재수입 검사는 모든 엔진의 동일 음영을 보장하지 않습니다.
