# ROOT103 — 왕관

무브랜드 원본 정적 전체 왕관 한 개입니다. 비압축 BLEND/FBX/GLB 각3LOD, 실제 대표 렌더3개, 사용자 문서·체크섬입니다. 추가 최종검사뷰11개와128px 식별성 이미지는 로컬에 보존합니다.

삼각형 14,592 / 7,680 / 3,840. 열린 원형 머리띠, 반복 첨두8개와 깊은 골, 실제 내부벽/두께, 하단의 둥근 띠 장식이 하나로 연결됩니다. 중앙은 위아래로 열려 있습니다. 보석 없이도 왕관 실루엣을 우선하며 색·보석·첨두수 변형은 별도 신규 종류가 아닙니다. 기존 체스 부품을 추출하지 않았습니다.

공개 연구 저장소의 고정 커밋 BOSS 왕관 전체 도판을 직접 확인했습니다. 원 촬영자·제조사·정확 치수는 미확인입니다. 비례·보이지 않는 밑면은 자체 일반화했으며 특정 역사유물이나 제조사 제품의 정확복원이 아닙니다. 참고사진·라벨·상표·사진 텍스처는 포함하지 않습니다.

실제128px 무라벨 렌더에서 열린 머리띠와 반복 첨두로 왕관이 읽히는지 검토자가 별도 확인했습니다. 관객시험이나 모든 사용자에 대한 보증은 아닙니다. 착용치수·금속품위·물성·안전·리그·콜라이더·Unity 인증은 없습니다.
