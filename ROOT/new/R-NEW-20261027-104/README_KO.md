# ROOT104 — 얼음틀

무브랜드 원본 정적 전체 얼음틀 한 개입니다. 비압축 BLEND/FBX/GLB 각3LOD, 실제 대표 렌더3개, 사용자 문서·체크섬입니다. 추가 최종 검사뷰11개와3LOD의128px 식별성 이미지는 로컬에 보존합니다.

삼각형 12,528 / 8,352 / 4,176. 길게 반복된 작은 테이퍼 홈14개, 열린 윗면과 닫힌 홈 바닥, 함께 이어진 상단과 실제 얇은 재질 벽을 갖춘 일체형 몰드입니다. 각 홈은 별도 신규 물건이 아니며 색·칸 수·재질 변경으로 종류를 늘리지 않습니다. 기존 도시락이나 냉장고 부품에서 추출하지 않았습니다.

고정 커밋 공개 연구 저장소의 BOSS 전체 얼음틀 사진형 도판을 직접 확인했습니다. 원 촬영자·제조사·정확 치수는 미확인입니다. 비례·보이지 않는 밑면·벽 두께·모서리 반경은 자체 일반화했습니다. 참고사진·라벨·상표·사진 텍스처는 포함하지 않습니다.

실제128px 무라벨 렌더에서 열린 작은 몰드 홈과 긴 전체 형태가 얼음틀로 바로 읽히는지 검토자가 확인했습니다. 관객시험이나 전체 사용자에 대한 보증은 아닙니다. 식품접촉·냉동적합·재질물성·열·얼음배출·안전·리그·콜라이더·Unity 인증은 없습니다.

낮은LOD의 모서리는 더 단순하고 무디노이즈 Cycles40샘플 렌더에 약간의 노이즈가 남습니다.6회 재수입 검사는 모든 엔진의 동일 음영을 보장하지 않습니다. 내부/밑면 추가검사뷰는 납품 대표3뷰 외에 로컬 보존됩니다.
