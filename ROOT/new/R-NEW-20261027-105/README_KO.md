# ROOT105 — USB 메모리

무브랜드 원본 정적 USB 메모리 모양 소품 전체 한 개입니다. 비압축 BLEND/FBX/GLB 각3LOD, 실제 대표 렌더3개, 사용자 문서·체크섬입니다. 추가 최종 검사뷰11개와3LOD의128px 식별성 이미지는 로컬에 보존합니다.

삼각형 10,412 / 4,364 / 1,564. 독립된 넓은 몸체, 장식 상판, 실제 열린 금속 커넥터 셸과 유지구멍2개, 지지된 일반화 절연 혀/접점4개를 포함합니다. 케이블이나 별도 뚜껑은 없습니다. 기존 게임패드/웹캠/스캐너의 플러그를 추출하지 않고 새 원본 전체를 만들었습니다. 색·용량표시·크기·커넥터 변형으로 종류를 늘리지 않습니다.

고정 커밋 공개 연구 저장소의 BOSS 전체 USB 도판을 직접 확인했습니다. 촬영자·제조사·정확 치수·용량은 미확인입니다. 치수와 보이지 않는 접점/절연체는 자체 일반화이며 사진에서 내부 전자회로를 검증한 것이 아닙니다. 참고사진·라벨·상표·사진 텍스처는 포함하지 않습니다.

실제128px 무라벨 렌더를 제작자는3LOD, 부모 검토자는LOD0/LOD2에서 직접 확인하여 독립 USB메모리로 읽히는지 판단했습니다. 관객시험이나 모든 사용자에 대한 보증은 아닙니다. 저장기능·용량·전기·USB규격호환·물성·안전·리그·콜라이더·Unity 인증은 없습니다.

낮은LOD의 둥근 모서리는 더 단순하고 무디노이즈 Cycles40샘플 렌더에 약간의 노이즈가 남습니다.6회 재수입 검사는 모든 엔진의 동일 음영을 보장하지 않습니다.
