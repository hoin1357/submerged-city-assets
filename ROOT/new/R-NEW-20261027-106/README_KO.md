# ROOT106 — 트라이앵글과 채 한 세트

열린 모서리의 둥근 금속 삼각봉과 검은 손잡이 채로 구성한 무브랜드 원본 정적 소품입니다. 전체 한 세트가 한 종류이며, 채나 색상·크기 변형을 별도 종류로 세지 않습니다. 기존 당구 큐·프레임·악기의 부품을 추출하지 않았습니다. 추가 걸이나 스탠드는 없습니다.

BLEND/FBX/GLB 각3LOD, 삼각형 4,992 / 2,304 / 768. 대표 실제 렌더3개와 사용자 문서·체크섬을 비압축으로 제공합니다. 추가 최종 검사뷰11개와3LOD128px 식별성 이미지는 로컬에 보존합니다.

공개 연구 저장소의 고정 커밋 BOSS 전체 사진을 직접 확인했습니다. 촬영자·제조사·정확 치수는 미확인이고, 치수·끝단 마감·손잡이 연결은 자체 일반화입니다. 사진이나 사진 텍스처·상표는 포함하지 않습니다. 둥근 봉은 양 끝이 막힌 실체이며 모서리 간격과 내부 공간이 열려 있습니다. 별도 채는 손잡이에 금속봉이 지지됩니다.

제작자는3LOD, 부모 검토자는LOD0/LOD2의 실제128px 무라벨 렌더를 직접 확인하여 학교 악기로 식별했습니다. 관객시험은 아닙니다. 소리·조율·주파수·물성·안전성·리그·콜라이더·Unity 작동 인증은 없습니다. 낮은LOD의 곡선은 더 단순하며, 무디노이즈 Cycles40샘플 렌더에는 약간의 노이즈가 남습니다. 재수입 검증은 모든 엔진의 동일 음영을 보장하지 않습니다.
