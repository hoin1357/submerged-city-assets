# ROOT108 — 나비넥타이

접힌 양 날개와 중앙 감싼 매듭, 일반화한 뒤쪽 고정부를 가진 무브랜드 원본 정적 나비넥타이 한 개입니다. 기존 리본·장식·의복 부품을 추출하지 않았고 색상·매듭·크기 변형을 별도 종류로 세지 않습니다.

BLEND/FBX/GLB 각3LOD, 삼각형 14,348 / 5,484 / 1,548. 대표 실제 렌더3개와 사용자 문서·체크섬을 비압축으로 제공합니다. 추가 최종 검사뷰11개와3LOD128px 이미지는 로컬에 보존합니다.

고정 커밋 BOSS 전체 사진의 날개·접힘·중앙 매듭을 직접 확인했습니다. 촬영자·제조사·정확 치수는 미확인입니다. 보이지 않는 후면과 고정부는 자체 일반화이며 사진에서 정확한 봉제·고정 기구를 확인했다는 주장이 아닙니다. 원본 사진·사진 무늬·상표는 포함하지 않습니다. 표면은 미세 직조를 생략한 단순화된 천이며, 접힘은 실제 기하입니다.

제작자는3LOD, 부모 검토자는LOD0/LOD2 실제128px 무라벨 렌더를 직접 확인하여 나비넥타이 식별성을 판단했습니다. 관객시험은 아닙니다. 실제 착용·고정 작동·봉제·물성·리그·콜라이더·안전·Unity 작동 인증은 없습니다. 낮은LOD 곡선과 접힘은 더 단순하며 무디노이즈 Cycles40샘플 렌더에 약간의 노이즈가 남습니다.6회 재수입 검증은 모든 엔진의 동일 음영을 보장하지 않습니다.
