# ROOT110 — 철사 종이클립

길쭉한 U자 곡선이 중첩되고 두 끝이 노출된 일반 종이클립 원본입니다. 하나의 연속된 닫힌 철사 메시이며 바인더클립 손잡이를 추출하지 않았습니다. 색상·크기·고리 수 변형으로 종류를 늘리지 않습니다.

BLEND/FBX/GLB 각3LOD, 삼각형 8,512 / 3,560 / 1,080. 대표 실제 렌더3개와 사용자 문서·체크섬을 비압축으로 제공합니다. 추가 검사뷰11개와 실제128px 식별성 이미지는 로컬에 보존합니다.

참고: expfactory/expfactory-experiments 고정 커밋49b8123f18b26d94dfc010bb8a6ec7458b265e2e, object_rating/images/BOSS_neutral/paperclip03.jpg의 전체 사진을 직접 확인했습니다. 원 촬영자·제조사·촬영 맥락은 독립적으로 확인하지 못했습니다. 사진을 매핑하거나 재배포하지 않고 원본 기하와 단색 PBR 재질을 제작했습니다. 치수·단면·미세 간극은 자체 일반화입니다.

제작자는3LOD, 부모 검토자는LOD0/LOD2 실제128px 무라벨 렌더에서 종이클립 식별성을 판단했습니다. 관객시험은 아닙니다. 초기128px 카메라 근접절단면 오류뷰는 비공개로 보존했고, 모델을 변경하지 않은 교정 카메라 렌더로 확인했습니다. 스프링·종이 고정력·물성·안전·리그·콜라이더·Unity 작동 인증은 없습니다. 저LOD에서 철사 단면과 굽힘 표면이 단순화됩니다. 무디노이즈 Cycles40샘플 렌더에 약간의 노이즈가 남으며6회 재수입 검증은 모든 엔진의 동일 음영을 보장하지 않습니다.
