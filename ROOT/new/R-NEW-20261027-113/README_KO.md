# ROOT113 — 반원 각도기

반원판, 직선 기준선, 중심 방사선과 바깥 눈금으로 구성한 학교용 각도기 원본 정적 소품 한 개입니다. 눈금은 판 윗면의 연결된 면에 직접 재질을 배정한 것으로 떠 있는 데칼이나 겹친 판이 아닙니다. 숫자·상표는 없으며 색상·눈금 개수 변형을 별도 종류로 세지 않습니다.

BLEND/FBX/GLB 각3LOD. 삼각형 57,834 / 19,596 / 5,118. 대표 실제 렌더3개와 사용자 문서·체크섬을 비압축 제공합니다. 추가 검사뷰11개 및3LOD128px 이미지는 로컬 보존합니다.

참고: expfactory/expfactory-experiments 고정 커밋49b8123f18b26d94dfc010bb8a6ec7458b265e2e의 BOSS_neutral/protractor.jpg 실제 사진을 직접 확인했습니다. 사진의 개별 권리는 미확인이고 저장소 소프트웨어 MIT 라이선스를 사진에 적용한다고 주장하지 않습니다. 사진/로고를 텍스처로 복사하거나 납품하지 않습니다.

폭150mm·두께1.8mm는 자체 근사치입니다. 뒤쪽 구조·불투명 플라스틱 재질·숫자 없는 눈금 간격은 일반화했습니다. 정확한 각도 측정기나 제조사 복원이 아닙니다. R1 저LOD 방사선 누락은 보존/HOLD하고 R2에서 복원했습니다. 저LOD에서는 곡면과 눈금 간격/폭이 더 단순합니다.

제작자는3LOD, 부모 검토자는LOD0/LOD2 실제128px에서 식별성을 판단했으며 실제 관객 시험은 아닙니다. 측정 정확도·물성·안전·리그·콜라이더·Unity 동작 인증은 없습니다. 무디노이즈 Cycles40샘플 이미지에 약한 노이즈가 남고 재수입 검사는 모든 엔진의 음영 일치를 보장하지 않습니다.
