# ROOT051 — 기존 유선 게임패드 품질 보완 수정본

기존 한 종의 같은 ID 보완이며 신규 종류 수는 0입니다. 최종 검토를 완료한 동일 ID 수정본입니다. 기존 선택 기록과 이전 공개 배치는 변경하지 않습니다.

기존 R8의 세 단계는 모두125,164삼각형으로 실제 감축 LOD가 아니었습니다. 수정본는 숨은 앞·뒤 셸 중복 캡을 제거하고 둘레를 연결한 다재질 폐쇄 셸을 사용합니다. 내부 제거와 외부 감축은 구분합니다. 수정된 LOD0 74,240삼각형 대비 LOD1 63,440 / LOD2 50,480으로 실제 단계별 감축입니다. 원본 파일이나 전체 고밀도 메시와 바이트 동일하다고 주장하지 않습니다.

버튼·스틱·십자키·후면 조절부·케이블·플러그의 식별 구조를 유지합니다. USB 몰딩의 금속 쪽 끝은400µm 연장하여 평면 맞댐 대신 실제 삽입 접합이 되게 했으며 금속 끝단 전체가 몰딩 내부에 놓이는 것을 볼록체 반공간 검사로 검증했습니다(최소 여유 약147.7µm). 나머지43개 부품의 좌표·UV·노멀·재질·변환 기록은 독립적으로 원본과 일치 확인했습니다. 급경사 면을 노멀만 옮겨 감추지 않고 국소 보호와 완만한 감축으로 보완합니다.

정적 소품이며 실제 작동·전기·인체공학·하중·안전·리그·콜라이더·Unity 실행 보증은 없습니다. 내부 지지와 짧은 전시용 케이블은 일반화했습니다. 실제128px 검토는 검토자 판단이지 관객 시험이 아닙니다. 포맷별 음영 및 렌더 노이즈는 동일성 보증 대상이 아닙니다.

BLEND/GLB/FBX 각3LOD, 실제 대표 렌더3개, 사용자 문서와 체크섬의 비압축 수정본입니다. 참고 사진·로고·사진 텍스처는 포함하지 않습니다. 수치 기술 검증은 통과했습니다. 실제 최종17뷰 검토와 정확한 파일 해시·writer 종료 증거는 수정본 영수증에 별도로 연결합니다. 이 배치에는 최종 검토된 수정본을 제공합니다.

LOD0 외부 좌표·UV·노멀은 원본과 일치하며, 내부 캡 제거와 둘레 결합은 별도 수정입니다. 낮은 단계의 양방향 표본 표면편차 최대는 약29.11µm이며 전역 Hausdorff 상한 보증은 아닙니다. 재수입 노멀 재구성 차이는 GLB 최대0.001478, FBX 최대0.008438로 원시 노멀 전달 통과와 구분하며 픽셀/음영 동일성을 주장하지 않습니다.
