# A02 비주거 78종 v2 검사 결과

판정: 파일 보존·선별 원본·재배치 검사 통과. 아래 한계가 있다.

- 정확한 78종: A012 18, A013 18, A014 16, A015 14, A016 12.
- LOD0 78 + LOD1 78 + COL 78, 총 234개 FBX는 이미 독립 검사된 해당 최종 파일과 바이트 단위로 같다.
- 70종은 기존 최종 검수 근거, 8종은 최종 승인된 출입구 수정 검수 근거와 연결했다. 전체 메시를 새로 독립 재검사했다고 주장하지 않는다.
- 복사 파일 357개의 바이트를 저장된 원본 해시와 다시 대조했다. 텍스처 40개와 개별 이미지 78개가 포함된다.
- 새 분류별 편집 원본 5개를 다른 위치에서 각각 다시 열었다. 234개 메시의 정점·면·UV 서명, 실측 외곽, 미터 단위와 피벗, 정식 재질명, 로컬 상대 이미지 경로를 확인했다.
- 기존 주거 메시·갤러리·검토용 인물은 source에 없다. 기본 통합 스크립트도 재배치된 폴더에서 실행해 정확히 78종만 조립했다.
- 새 분류별 시트 5장은 확인된 78개 이미지로만 합성했다. A012/A016의 수정 대상 8개는 모두 최신 출입구 이미지다.
- 78개 에셋의 실제 크기 메타데이터 스키마와 치수 별칭 일치를 확인했다.
- 기존 전체 A02 ZIP과 출입구 패치 ZIP은 동결 해시와 동일하다.

## 중요한 한계
Unity Editor·C# 컴파일·실행·물리·FPS는 검사하지 않았다. 상점 수정 6종의 문턱 0.13m가 남아 있고, 실제 컨트롤러의 통과는 별도 확인해야 한다. 수정 8종은 상·하단 1mm 접촉 허용오차로 1.80m 인물과 2.10m 여유 프리즘을 검사한 기존 근거를 유지한다. 국소 노출면 변화 표본 최대 약 5.5mm를 허용한 결과이며, 출입구 밖의 모든 정점이 동일하다는 뜻은 아니다.

정적 비볼록 충돌체, 타일형 중첩 UV0, 미제공 UV1의 제한을 유지한다. LOD 전환·밀집 장면 부하·문/지붕 삽입물 조립은 프로젝트에서 검증한다. 분류별 이미지의 각 타일은 개별 프레이밍이므로 실제 크기 비교 자료가 아니다.

최종 ZIP의 CRC, 파일별 해시, 분할 파일 무결성은 별도의 패키지 보고서에서 확인한다.
