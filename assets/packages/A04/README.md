# A04 지붕·옥상 에셋 78종

두 패키지는 같은 78종의 사용용 파일과 편집용 파일입니다. LOD·충돌체·편집 오브젝트를 별도 에셋으로 세지 않습니다.

- PUBLIC_CONSUMER_v2: 기본 FBX 78개, LOD1 78개, 정적 충돌체 78개, 텍스처 40개, 미리보기 78개와 사용 설명.
- EDITABLE_PUBLIC_v4: 편집 가능한 master.blend, 텍스처 40개와 설명.

## 다운로드와 복원

이 폴더의 .zip.001부터 마지막 번호까지 두 묶음의 모든 분할 파일을 받고 PARTS.json과 combine.py를 같은 폴더에 둡니다. Python 3.8 이상에서 python combine.py를 실행하면 각 조각과 전체 SHA-256을 검증하고 ZIP 두 개를 복원합니다. 같은 이름의 기존 ZIP은 덮어쓰지 않습니다. 실패한 .assembling 파일은 확인 후 정리하고 다시 실행하세요.

복원한 ZIP을 각각 풀고 내부 README를 읽으세요. models와 textures, master.blend와 textures의 상대 위치를 유지해야 합니다. 분할 파일 하나만 압축 해제할 수는 없습니다.

## 검증과 한계

FBX의 기하·UV·재질 수치는 유지하고 텍스처 경로만 정리했습니다. 대표 모델 8개를 Blender 4.3.2에서 다시 불러와 확인했습니다. 편집용 파일은 독립된 압축 해제 위치에서 스크립트 실행 없이 열어 24개 텍스처가 패키지 내부에서 연결됨을 확인했습니다. 이미지 픽셀은 보존했습니다.

이는 모델 사용 및 편집을 위한 정리본이며 생성 코드, 과거 체크포인트, 내부 기록, 외부 참고 사진은 포함하지 않습니다. 전체 제작 프로젝트의 무손실 백업을 의미하지 않습니다. Unity 실행, 물리, NavMesh, 성능 및 플레이어 식별 테스트는 완료되지 않았습니다. 새 배포 라이선스나 권리 양도를 부여하지 않습니다.

편집용 v4는 사용되지 않는 문자열 버퍼도 정리한 최신판입니다. 모델의 기하와 재질은 동일합니다.
