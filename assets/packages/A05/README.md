# A05 출입구·창호·외부 접근 구조 90종

PUBLIC_CONSUMER_v1과 EDITABLE_PUBLIC_v2는 같은 90종의 사용용·편집용 파일입니다.

- 사용용: LOD0 FBX 90개, LOD1 FBX 90개, 정적 충돌 FBX 90개, 텍스처 PNG 25개, 미리보기 JPEG 90개.
- 편집용: 개별 Blender 파일 90개와 텍스처 PNG 25개. 단일 통합 장면이 아닙니다.

## 다운로드

모든 .zip.001 및 .zip.002 파일, PARTS.json, combine.py를 같은 폴더에 받으세요. Python 3.8 이상에서 python combine.py를 실행하면 조각과 전체 SHA-256을 검증하며 ZIP 2개를 복원합니다. 기존 ZIP은 덮어쓰지 않습니다. 실패한 .assembling 파일은 확인 후 정리하세요. 두 ZIP은 서로 별도 폴더에 풀고 각각의 README_KO.md를 읽으세요.

## 범위와 한계

대표 FBX 16개와 편집용 Blender 90개를 검사했습니다. 편집용 파일의 848개 이미지 참조가 독립 압축 해제 폴더 내부에서 연결되었고 기하·UV·재질·변환을 원본과 비교했습니다. 문·창을 넣을 실제 벽 개구, 움직이는 부품의 충돌과 인터랙션은 프로젝트에 맞춰 설정해야 합니다.

생성 코드·외부 참고사진·내부 작업 기록은 포함하지 않습니다. 전체 제작 프로젝트의 무손실 백업이 아닙니다. Unity 실행·물리·플레이어 식별·출시 준비 완료를 보장하지 않습니다. LOD와 충돌체는 추가 에셋으로 세지 않습니다. 별도 공개 배포 라이선스를 부여하지 않습니다.
