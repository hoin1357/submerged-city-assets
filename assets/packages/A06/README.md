# A06 실내 건축 108종

사용용 PUBLIC_CONSUMER와 편집용 EDITABLE은 같은 108종입니다. 사용용에는 LOD0/LOD1 FBX 각 108개, 정적 COL 108개, 텍스처 25개와 미리보기 108개가 있습니다. 편집용에는 개별 Blender 파일 108개와 텍스처 25개가 있습니다.

## 다운로드

이 폴더의 분할 파일 전부(.zip.001부터 마지막 번호까지), PARTS.json, combine.py를 받으세요. Python 3.8 이상에서 python combine.py를 실행하면 조각 및 전체 SHA-256을 확인하고 ZIP 두 개를 복원합니다. 각각 별도 폴더에 풀고 내부 README_KO.md를 읽으세요. 기존 ZIP은 덮어쓰지 않습니다.

## 확인 범위

FBX 대표 16개와 편집용 108개를 Blender에서 다시 읽어 기하·UV·재질·변환을 대조했습니다. 완성 ZIP을 독립 위치에 풀어 512개의 이미지 참조가 패키지 내부에서 연결되는지 확인했습니다. LOD1 중 71개는 형태 보존을 위해 원본과 동일 비용이며 성능 절감본이 아닙니다.

계단에는 별도 난간이 필요하고 수직 샤프트에는 이동 시스템과 가장자리 보호가 필요합니다. 자동 접속이나 임의의 방 조립을 보장하지 않습니다. Unity 실행·물리·성능·플레이어 식별 검증은 별도입니다. 참고 사진·생성 코드·내부 작업 기록은 제외되어 원본 제작 프로젝트 전체의 무손실 백업이 아닙니다. 별도의 공개 배포 라이선스는 부여하지 않습니다.
