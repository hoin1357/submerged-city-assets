# B01 도로·보도 86종

사용용 패키지에는 LOD0/LOD1 FBX 각 86개, 정적 COL 86개, 텍스처 25개와 대표 미리보기 86개가 있습니다. 편집용 패키지는 개별 Blender 라이브러리 86개와 텍스처 25개입니다. 같은 에셋의 LOD·충돌체를 추가 종류로 세지 않습니다.

## 다운로드

모든 분할 파일(.zip.001부터 마지막 번호까지), PARTS.json, combine.py를 같은 폴더에 받아 Python 3.8 이상에서 python combine.py를 실행하세요. 조각과 전체 SHA-256을 검사하며 ZIP 두 개를 복원합니다. 기존 ZIP은 덮어쓰지 않습니다. 각각 별도 폴더에 풀고 내부 README_KO.md를 읽으세요.

## 사용과 검증 범위

Blender 대표 FBX 18개와 편집용 86개를 다시 열어 기하·UV·재질·변환과 패키지 내부의 352개 이미지 참조를 확인했습니다. 편집용 자동 Python 실행은 필요 없습니다.

차선 표시가 완성된 도로가 아닙니다. 차도·연석·보도 오프셋, 나무 구멍과 인서트의 정확한 짝, 배수 목과 계단의 빈 공간, 묻혀야 하는 기초 조건은 내부 설명을 따르세요. COL은 정적 비볼록 용도이며 동적 차량 조향·서스펜션·물리와 Unity 실행은 검증하지 않았습니다.

외부 참고 사진·생성 코드·내부 검수·과거 작업 기록·설치 PDF·폰트는 포함하지 않습니다. 모델 사용·편집용 정리본이며 전체 제작 프로젝트의 무손실 백업은 아닙니다. 새 공개 배포 라이선스를 부여하지 않습니다.
