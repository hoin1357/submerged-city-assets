# B02 가로시설·교통 제어 장치 96종

최종 native 릴리스의 가로등, 신호 지주·신호등, 표지판, 벤치, 휴지통, 거치대, 볼라드·게이트, 공공 서비스기기와 임시 통제장비입니다. 사용용은 LOD0/LOD1 FBX 각 96개, 정적 COL 96개, 자체 PBR 텍스처 65개, 대표 JPEG 96개와 사용 설명입니다. 편집용은 개별 Blender 파일 96개와 텍스처 65개입니다.

## 다운로드

모든 .zip.001 및 .zip.002 파일, PARTS.json, combine.py를 같은 폴더에 받으세요. Python 3.8 이상에서 python combine.py를 실행하면 조각과 전체 SHA-256을 검사해 ZIP 두 개를 복원합니다. 기존 ZIP은 덮어쓰지 않습니다. 각각 별도 폴더에 풀고 README_KO.md와 OPERATING_LIMITS.md를 읽으세요.

## 확인 범위와 한계

대표 FBX 20개와 편집용 96개를 다시 읽어 기하·UV·재질·변환을 비교했습니다. 완성 ZIP을 독립적으로 풀어 1,008개 텍스처 참조가 패키지 내부에서 로드됨을 확인했습니다. 내장 참고사진·packed 이미지·참조 이미지 empty·내장 스크립트는 없습니다.

리깅되지 않은 정적 기하이며 문·게이트·접이·텔레스코픽 동작이나 교통 시스템이 완성된 상태가 아닙니다. 흰 표지판은 빈 판형이며 신호 렌즈는 기본 비발광입니다. 투명창 재질, 2m 보행 통로, 0.50m 연석 이격, 전개·정비 영역과 정적 비볼록 COL을 프로젝트에 맞춰 확인하세요.

외부 참고 사진·생성 코드·내부 검수·출처·과거 작업 기록은 제외했습니다. 전체 제작 프로젝트의 무손실 백업이나 Unity 실행·물리·구조 안전 인증을 의미하지 않습니다. 새 배포 라이선스는 부여하지 않습니다.
