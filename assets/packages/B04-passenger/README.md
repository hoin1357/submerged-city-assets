# B04 PASSENGER12 — 공개 사용 패키지

기존 정적 차량 12종의 대표 배포 파일을 보존한 정리본입니다. 신규 종류·완성품 인증을 뜻하지 않으며, LOD와 COL은 별도 차량으로 세지 않습니다.

## 구성과 사용

fbx/LOD0 및 fbx/LOD1에 시각 모델, collision에 정적 충돌 메시, textures에 공용 60개 PBR 맵, previews/primary에 차량별 2개의 기존 대표 PNG가 있습니다.

폴더 구조와 텍스처 파일명을 유지하세요. 단위는 미터입니다. FBX 내보내기 기준은 Y 위쪽 / -Z 전방이며 Blender 내부 축과 구분해야 합니다. 가져오는 프로그램의 축·단위 자동 변환을 확인하고, 추가 100배 스케일을 임의로 적용하지 마세요. 커스텀 노멀, 면별 스무딩, 메시 로컬 원점, 에셋 루트와 바퀴 피벗을 보존하세요. 노멀을 일괄 재계산하면 표면 음영이 달라질 수 있습니다.

## 재질

저장된 Blender PBR 노드와 함께 제공한 맵이 기준입니다. Base color는 sRGB, 데이터 맵은 Non-Color를 유지하세요. FBX 수신 프로그램마다 재질 해석이 다르므로 맵을 다시 연결해야 할 수 있습니다. 유리의 투명도·반사는 다른 렌더러에서 자동으로 동일하게 보장되지 않습니다.

## 사용 제한

주차하거나 장비를 접어 둔 정적 모델입니다. 문 그룹·바퀴 피벗·장비 데이터는 작동 리그 또는 운전 컨트롤러가 아닙니다. 문 애니메이션, 서스펜션, 동적 차량 물리, 장비 작동·안전 인증은 포함하지 않습니다. 닫힌 문을 통과시키는 기능은 별도로 구현해야 합니다.

COL은 비볼록 정적 메시이며 동적 강체나 주행 차량용 충돌 프리셋으로 그대로 사용하면 안 됩니다. Unity Editor에서 검증한 프리팹, 런타임 성능·충돌 설정 및 플레이어 인지성 검증은 제공 범위에 포함되지 않습니다.

## 검증과 제외 항목

기존 모델의 형상·UV·재질·커스텀 노멀·스무딩·피벗을 보존하면서 파일 경로와 비기능성 제작 메타데이터를 정리했습니다. 분리된 임시 폴더에서 Blender 파일과 대표 FBX를 다시 열어 검사했습니다. 이는 Unity 또는 게임 플레이 검증과 다릅니다. SHA256SUMS.json은 이 패키지 파일 무결성 목록입니다.

생성 코드, 수치 중간 데이터, 내부 검토·작업 이력, 외부 참고 사진, PDF와 폰트는 제외했습니다. 전체 제작 프로젝트의 무손실 백업 또는 소스 재생성을 제공하는 패키지가 아닙니다. 새로 재생성·수정한 파일은 기존 검사 결과를 자동 승계하지 않습니다. 기존 원본은 별도로 보존됩니다.

## 차량별 보존 주의

- 유리의 기존 기준은 transmission 0.92, IOR 1.45, alpha 1.0입니다.
- B028-10 MPV의 아주 작은 부품은 노멀 저장을 위한 별도 로컬 좌표 원점이 있습니다. 이 원점은 운동 피벗이 아닙니다.
- B028-11은 중앙 엔진 쐐기형 쿠페입니다.
- 저장·가져오기 노멀은 부동소수점 표현 오차를 가질 수 있습니다. 이번 정리는 원본과의 동일성을 검사했으며 새 게임 엔진의 허용 오차를 보증하지 않습니다.

## Download and integrity
Download every .part file, PARTS.json and combine.py into one folder. Run `python combine.py` with Python 3.8+. Part and complete ZIP SHA-256 are checked; existing ZIPs are not overwritten. Committed Git object hashes are compared with local byte-derived hashes; this is not a fresh full-byte download test.
