# 신규 생활용품 6종

- ENA_A2_public_clean_v1.zip: 빨래집게, TV 리모컨 2종.
- EASY_B_FOUR_PUBLIC_v2.zip: 쓰레받기, 칫솔, 슬리퍼 한 켤레, 미국형 3구 멀티탭 4종.

각 ZIP은 분할 파일이 아니므로 바로 다운로드해 압축을 풀 수 있습니다. 편집용 Blender 파일과 FBX LOD0/1/2, 간단한 배치용 충돌 메시 및 렌더가 들어 있습니다. B 패키지는 GLB도 포함하며, 6종의 갤러리용 GLB는 저장소 gallery/models/EVERYDAY에 있습니다.

쉽게 알아볼 수 있는 생활용품 시각 후보입니다. 슬리퍼 두 짝은 한 종류이고 LOD·충돌체는 추가 에셋으로 세지 않습니다. 원본과 기하·UV·재질·변환을 비교했으며 외부 참고 사진이나 비공개 작업 기록은 포함하지 않습니다. Unity 실행, 실제 플레이어 식별 및 게임 물리 테스트는 아직입니다. 새 배포 라이선스를 부여하지 않습니다.
