# FURNITURE40 공개 에셋 백업

기존 가구·조명 40종(C002, C004, C005, C007 각 10종)의 대표 버전 백업입니다. 시각 검토 후보이며 신규 제작 또는 완성품 인증을 의미하지 않습니다.

편집용 Blender 파일, 기존 모델 내보내기 파일과 LOD·충돌 메시, 필요한 텍스처 및 대표 이미지를 포함합니다. 정확한 파일 구성은 ZIP 내부 목록을 참고하세요.

## 다운로드와 복원

이 폴더의 모든 `FURNITURE_LIGHTING_40_PUBLIC.zip.part*` 파일, PARTS.json, combine.py를 같은 폴더에 내려받고 Python 3.8 이상에서 `python combine.py`를 실행하세요. 분할 파일과 복원 ZIP의 크기 및 SHA-256을 검사합니다. 이미 같은 이름의 ZIP이 있으면 덮어쓰지 않습니다.

전체 ZIP: 55751502바이트, SHA-256 `9f92e50d79bbc19d30ed828dced32f36d37341cc71c5c2828ad3092c611c24cf`.

## 검증 범위

로컬 ZIP CRC와 파일 해시 및 분할 Git 객체 해시를 확인한 패키지입니다. 커밋 후 원격 Git 객체 해시를 비교하며, 전체 바이트를 새로 다운로드한 검증과는 다릅니다. Unity 통합·런타임 성능·충돌 최적화·플레이어 인지성·상용 출시 준비는 검증되지 않았습니다.

외부 참고 사진, 내부 검토·로그와 중간 버전은 제외했습니다. 전체 제작 프로젝트의 무손실 백업이 아닙니다.

## 명칭 정정

ZIP 내부 CATALOG의 다음 두 이전 명칭 대신 아래 명칭을 사용하세요. 모델 파일은 변경되지 않았습니다.

- C004-07: ‘펼친 목재 소파베드’ → ‘팔걸이 데이베드’
- C005-10: ‘회전 수납통 장’ → ‘기울임식 쓰레기통 수납장’

이 정정은 함께 제공되는 CATALOG_CORRECTIONS.json에도 기록되어 있습니다.
