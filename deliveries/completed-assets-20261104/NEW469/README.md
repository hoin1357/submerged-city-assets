# NEW469: kingpost hang glider

Three LODs, each in BLEND, FBX and GLB (nine model files). Any accompanying PNG files are original required texture support. Keep PNGs beside the models. These are original visual props, not certified functional products.

## Limitations
Static kingpost hang glider visual model based on multiple photographs and manufacturer span 10.1m sail, overall 10.148m incl rounded frame. No flight, folding, aerodynamics or safety certification, some hidden construction inferred. 9 reopened exports inspected; independent real cap-vertex finite support tests for 29 structural endpoints each and batten ends 192/160/128 per LOD with displacement/deletion negatives. Local stylized solid overlaps incl kingpost through sail; no blanket collision-free or engineering claim. BLEND/FBX/GLB positions max 1.74 micrometres, normal max 0.034 degrees, UV/PBR within stated audit tolerances; nearest triangle matching not unique bijection.
