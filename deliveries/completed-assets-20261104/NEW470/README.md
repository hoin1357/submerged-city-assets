# NEW470: pedal timpani

Three LODs, each in BLEND, FBX and GLB (nine model files). Any accompanying PNG files are original required texture support. Keep PNGs beside the models. These are original visual props, not certified functional products.

## Limitations
Pedal timpani static model from Yamaha TP-7326R references, measured envelope .80×.94×.85m. Pedal internal mechanism and motion unverified: no animation or safety claim. Actual finite mesh support/pedal weld/pitch mount/frame/casters and drum inner-wall clearance independently sampled with removal and penetration controls. Design radial clearance 0.2mm is not actual polygon minimum: central hinge 0.156/0.132/0.080mm and bearings 0.194/0.192/0.092mm by LOD. Surface/contained tests are bounded, not continuous motion certification. Original 9 reopened rendered, material/UV/normal correspondence tested;
