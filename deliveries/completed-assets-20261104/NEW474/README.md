# NEW474: crank driven hurdy gurdy

Three LODs, each in BLEND, FBX and GLB (nine model files). Any accompanying PNG files are original required texture support. Keep PNGs beside the models. These are original visual props, not certified functional products.

## Limitations
Original stylized crank-driven hurdy-gurdy visual prop, not an exact museum replica. Nine actual files in three LODs (20858/9852/4328 triangles), six original embedded PBR textures. Independent component geometry, neutral correspondence at unchanged 0.2 micrometre position threshold, normals/UV/material/winding and raw GLB normal payload checks pass; 11 exact-predicate assertions pass. A four-second crank/shaft/wheel revolution is baked for FBX/GLB; native control clamps to [0,1]. Motion/contact checks cover 24 normalized phases including seven off-grid phases, not continuous collision or volumetric proof. Keys, tangent blocks, pegs and lid are static. No acoustics, sound, friction, tension, string vibration, physical playability or engineering certification. Tiled overlapping UVs are not a lightmap atlas. GLB validation imports use NORMALS shading. No Unity import test, prefab, runtime controller, collider, LODGroup or physics certification.
