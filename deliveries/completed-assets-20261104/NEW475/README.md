# NEW475: wired optical mouse

Three LODs, each in BLEND, FBX and GLB (nine model files). Any accompanying PNG files are original required texture support. Keep PNGs beside the models. These are original visual props, not certified functional products.

## Limitations
Original unbranded wired optical mouse game prop. Body, continuous cable and USB-A plug form one asset. Nine model files, LOD triangles 18288/9348/4752, seven scalar PBR materials and no image texture dependencies. Authored body approximately 116 x 66 x 38 mm is not a measured replica; cable is intentionally shortened to approximately 0.558 m and static, without cable physics. Four-second visual clip: one wheel revolution then independent left/right button presses up to 0.45 mm; translations are artist-authored, not hardware hinge or switch measurements. Author reports 33 sampled phases including off-grid/full-press positions and five fixed-interface witnesses; sampling does not prove continuous collision freedom or no volumetric containment. Declared unchanged 0.2 micrometre neutral position, normal/UV/material/winding and 1 micrometre sampled-motion comparisons pass. Component closedness does not make the multipart assembly one Boolean solid. UV0 overlaps/tiles, not a lightmap atlas. GLB checks explicitly use NORMALS shading. No live game-engine/Unity test, prefab, runtime controller, LODGroup, collider, physics, manufacturing, electronics, optics, USB communication, powered illumination, sensor tracking, sound or functional hardware certification. Original smooth shading retained; only USB tongue geometry was extended relative to original.  Independent final-byte re-audit also passes nine fresh reopens and six cross-format comparisons. It independently recomputed zero moving/fixed crossings at 29 unique normalized times, not the earlier duplicate-counted 31. Independent full self-intersection sweep was not repeated; author exact-sweep results were matched to current hashes. USB tongue/grip intended static overlap is confirmed in all nine files.
