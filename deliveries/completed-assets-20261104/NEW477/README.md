# NEW477: classic red plastic pushpin

Three LODs, each in BLEND, FBX and GLB (nine model files). Any accompanying PNG files are original required texture support. Keep PNGs beside the models. These are original visual props, not certified functional products.

## Limitations
Original unbranded red plastic pushpin with steel shaft, one static prop. Nine model files, LOD triangles 2176/1056/416, two individually closed positive-volume components, two scalar PBR materials and no image texture dependencies. Estimated 9.6 x 9.6 x 19 mm envelope, approximately 9 mm exposed shaft and 0.86 mm shank. Reference point is hidden in wood; complete point, underside, internal seat, hidden construction and dimensions are inferred. Steel shaft intentionally overlaps plastic by approximately 1.2 mm; not one Boolean-unioned or globally collision-free solid. Independent rerun verifies actual nine component geometry/contacts; original strict 1e-5 normal-vector comparison FAILS all six export routes, retained structurally. Separate author-selected 0.05 degree pass is not user-approved. UVs nondegenerate within tile and no intra-mesh positive-area overlaps; reuse between two materials is intentional. No rig, animation, puncture behavior, physical strength, manufacturing, dynamics, collision proxy, engine LOD group or live-engine certification. Cutaway is diagnostic preview-only geometry. Blind recognition is one qualitative reviewer, not a population study.
