# NEW479: original frosted household screw-base bulb

Includes three standalone LODs, each in Blender, FBX and GLB (nine model files). Keep any supplied PNG atlases beside the models. No automatic LOD switching is configured.

## Scope and limitations

Opaque, unlit exterior only; no hollow glass, filament or LED internals. Nominal 60 mm diameter × 110 mm height is an artistic assumption. LOD2 has visible crown faceting. UV density is nonuniform and distortion is not optimized for painting/baking. Cross-format normal comparison used a 0.05-degree author-selected tolerance, not bitwise equality. No socket-fit, E26/E27, electrical, thermal or mechanical certification.

Geometry, transforms, hierarchy, UVs, normals and PBR data are preserved relative to each corresponding source format. Publication changes only remove private file-browser/render/header paths or make texture paths portable. Original texture bytes are preserved. Blender 4.3.2 reopen equality is not certification for other applications. Cross-format importer differences already present in the originals remain. No engine performance or collision claim. Historical global design uniqueness is unproven.

## Authorship, sources and rights

Original generic unbranded model. Reference photographs were used for visual research only; no photographs, source-photo pixels, scripts or private research records are distributed here. Model proportions and hidden details include artistic assumptions. Source-photo licenses do not themselves license the new geometry or clear product-design, patent or trademark rights.
