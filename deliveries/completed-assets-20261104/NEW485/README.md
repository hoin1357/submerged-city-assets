# NEW485: complete retractable dog leash with oval grip, tape and swivel snap

Includes three standalone LODs, each in Blender, FBX and GLB (nine model files). Keep any supplied PNG atlases beside the models. No automatic LOD switching is configured.

## Scope and limitations

Static dog-leash assembly with oval grip, tape and snap; no internal reel or spring. Intentional seating intersections are not physical fit or bounded penetration certification. Plain-color UV atlas has nonuniform density. No retraction, brake, swivel or gate motion, force, load, animal-safety, collision or manufacturing validation.

Geometry, transforms, hierarchy, UVs, normals and PBR data are preserved relative to each corresponding source format. Publication changes only remove private file-browser/render/header paths or make texture paths portable. Original texture bytes are preserved. Blender 4.3.2 reopen equality is not certification for other applications. Cross-format importer differences already present in the originals remain. No engine performance or collision claim. Historical global design uniqueness is unproven.
