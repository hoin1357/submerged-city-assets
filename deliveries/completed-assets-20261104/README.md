## Scope, verification and licensing

Read each design's README for its exact purpose, source attribution, material/import caveats and tests. These are digital visual assets, not engineering, manufacturing, medical, electrical or traffic-safety certifications. Runtime LOD switching, collisions, target-engine setup and physical operation are not implied. Some mechanical motion is illustrative only. Retained strict cross-format diagnostic differences, including NEW473 and NEW477, are disclosed rather than hidden.

Published model copies remove private application paths and metadata. Reopened same-format geometry, hierarchy, transforms, UVs, normals and material content were compared against the selected release. Supported animation, driver and constraint data are retained where present. Required textures are original image assets, not photographs copied from reference sources. No source reference photographs are embedded in this collection.

NEW482 retains its specifically documented CC BY-SA 4.0 model-adaptation license and attribution. Reference-photo licenses do not automatically license every other model. No blanket collection license, product-design clearance or trademark clearance is asserted; consult the individual README and repository terms.

The manifest lists every payload file except itself with byte sizes and SHA-256. Publication verification compares content-addressed Git object identities and file sizes to these local verified copies. A fresh independent download of all remote binary bytes is not claimed.
