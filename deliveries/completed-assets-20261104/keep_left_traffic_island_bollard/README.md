# Keep-left traffic-island bollard

Original complete static exterior prop. This is a self-contained rounded white housing, blue circular down-left arrow sign, yellow front and side panels, flared foot, mounting rim and hardware. It is not a flat sign, truncated head, generic post, exact branded replica, or a complete traffic island. No manufacturer logo, identifier or photographed texture is included.

## Delivery

Three manually designed detail levels, each supplied as Blender 4.3.2, binary FBX and self-contained GLB. Clean model files contain meshes only, no cameras, lights, ground, external images, animation or rig. Preview studio exists only in rendered images. All model materials use constant portable PBR colors, with subtle emission as a visual hint, not simulated internal light hardware. FBX material translation can vary by application; GLB and Blender are recommended for predictable PBR.

Nominal size: 0.408 m wide × 0.3203 m maximum depth including hardware × 1.018 m tall. Dimensions are approximate visual working assumptions, not measured manufacturer dimensions. Base sits at Z=0; Blender front faces -Y and up is +Z. FBX/GLB are exported Y-up using Blender's standard conversion. Object origins are inherited from procedural construction; the assembly coordinates share ground centre at the world origin. Multiple closed mesh components intentionally overlap at their assembly joints. Each mesh is outward oriented. A hollow electrical interior is not reconstructed.

LOD0 retains rounded corners, a 64-sided direction disk, visible screw recesses and mounting bolts. LOD1 retains 32-sided disk and base screw heads while dropping recesses and mounting bolts. LOD2 has a 20-sided disk, simplified edge radii and no small hardware. Every LOD retains the complete silhouette, volumetric housing, foot, readable blue/white arrow, and front/side panels. The LODs are separate exports, not distance-switch logic.

UVs are provided in one deterministic packed 0–1 layout per LOD, with connected coplanar triangles grouped into planar charts. Constant materials need no image files; the UV layout is ready for subsequent texture authoring. No baked texture, lightmap UV channel, collision mesh, engine import setup, LOD transition setup, electrical hardware or animation is claimed.
