# NEW502: rigid-spout thumb-lever oil can

Original static visual 3 D prop. Nine model files: LOD0, LOD1 and LOD2, each supplied as BLEND, FBX and GLB. Only the accepted final static models are included.

## Materials and use

The models use embedded scalar PBR materials. No external textures, material companion files, manufacturer photographs or reference PDFs are required or included. Blender import checks do not certify every engine or renderer. No rig, animation, physical performance, safety, manufacturing or exact commercial-product replica is guaranteed. Lower LODs may show deliberate faceting.

UV layouts are provided. Many use separated triangle charts; continuous paint-ready unwrapping and universal lightmap/baking suitability are not guaranteed.

## Asset-specific scope and limitations

- Static exterior only, no pump animation, fluid path simulation, leakproofness, pumping or safety certification.
- Published tube length is 135 mm. Nominal manufacturer height 120 mm and base 135×70 mm are not a verified fitted envelope. Model assembled bounds and component dimensions are separately documented estimates.
- Lower LODs reduce curved grip/lever, collar and rim details; no engine runtime or switching-distance validation.
- LOD0 triangle UV charts are nonoverlapping but highly segmented. Scalar PBR has no image-texture dependency.
- Measured Blender GLB reimport component-normal exception is explicitly accepted for static visual use; original strict failure remains recorded.
