# NEW506: wooden forked boot jack

Original static visual 3 D prop. Nine model files: LOD0, LOD1 and LOD2, each supplied as BLEND, FBX and GLB. Only the accepted final static models are included.

## Materials and use

The models use embedded scalar PBR materials. No external textures, material companion files, manufacturer photographs or reference PDFs are required or included. Blender import checks do not certify every engine or renderer. No rig, animation, physical performance, safety, manufacturing or exact commercial-product replica is guaranteed. Lower LODs may show deliberate faceting.

UV layouts are provided. Many use separated triangle charts; continuous paint-ready unwrapping and universal lightmap/baking suitability are not guaranteed.

## Asset-specific scope and limitations

- Static visual prop only; no load capacity, traction, ergonomic, mechanical, manufacturing or safe boot-removal certification.
- Only complete 115 x 326 x 91 mm envelope is manufacturer-dimensional grounding. Detailed geometry and hidden joinery remain estimated.
- Scalar pale-wood and dark-rubber PBR only; no photographic wood grain, texture or normal-map dependency.
- LOD0 tread is a visual corrugation approximation. LOD1 retains seven coarser parallel ribs with reduced curve detail; not exact physical rib reproduction.
- LOD2 has visibly faceted fork/liner and flat polygonal pads with tread relief omitted; distance use only.
- Concealed shallow part overlaps are intentional seated static contacts, not a manufacturing joint specification.
- Blender 4.3.2 actual-file audit only; no universal importer or target-engine runtime validation.
- Blind recognition retained 80% thumbnail and 85% full-view confidence with support-ramp/foot-support alternatives.
