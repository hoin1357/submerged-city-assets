# NEW517: open pouring pitcher

Original static visual 3 D prop. Nine model files: LOD0, LOD1 and LOD2, each supplied as BLEND, FBX and GLB. Only the accepted final static models are included.

## Materials and use

The models use embedded scalar PBR materials. No external textures, material companion files, manufacturer photographs or reference PDFs are required or included. Blender import checks do not certify every engine or renderer. No rig, animation, physical performance, safety, manufacturing or exact commercial-product replica is guaranteed. Lower LODs may show deliberate faceting.

UV layouts are provided. Many use separated triangle charts; continuous paint-ready unwrapping and universal lightmap/baking suitability are not guaranteed.

## Asset-specific scope and limitations

- Acceptance is for an original unbranded static scalar-PBR visual prop with a visibly faceted low-poly finish, not seamless smooth glazed ceramic or an exact manufacturer replica.
- Final LOD0 has visible bands/facets especially near base, rim and handle roots; coarser LODs make polygonal transitions more apparent.
- The blind 99%/99% recognition judgments belong to the original smooth-shaded gray prototype. Final revised geometry and flat shading received informed inspection, not a repeated blind test or inherited confidence score.
- Hidden interior, wall, base, lip channel, grip and roots are original artist estimates from limited photographs. Thickness values are finite samples/radial or axial ray distances, not an exhaustive minimum normal wall-thickness proof.
- Signed mesh volume is ceramic-material volume, not cavity volume or capacity. No fluid behavior, food-contact safety, strength, thermal, ergonomics, manufacturing or physical-use certification.
- Floating-point tests use documented weld, intersection and area tolerances. No exact-arithmetic proof of absence of every sub-tolerance defect or point/edge tangency. Shared-vertex noncoplanar testing supplements the initial exclusion, and coplanar shared-edge overlaps are explicitly tested.
- Checks use Blender 4.3.2 and direct GLB payload parsing. No universal-engine, runtime collision, animation or other engine behavior certification.
- UV0 is globally bounded and nonoverlapping for the scalar-material asset. LOD2 uses separate triangle charts; no production texture painting layout or texture set is claimed.
- GLB uses opaque double-sided materials. Geometry validity is established independently of visibility, so double-sided rendering is not treated as proof of a closed shell.
- FBX imports have negligible axis-conversion rotation with identity matrix error below 1e-6; applied identity is accepted within import tolerance, not bitwise equality.
