# NEW551: Standalone twin-core hollow concrete masonry block

Original static visual 3 D prop. Nine model files: LOD0, LOD1 and LOD2, each supplied as BLEND, FBX and GLB. Only the accepted final static models are included.

## Materials and use

The models use embedded scalar PBR materials. No external textures, material companion files, manufacturer photographs or reference PDFs are required or included. Blender import checks do not certify every engine or renderer. No rig, animation, physical performance, safety, manufacturing or exact commercial-product replica is guaranteed. Lower LODs may show deliberate faceting.

UV layouts are provided. Many use separated triangle charts; continuous paint-ready unwrapping and universal lightmap/baking suitability are not guaranteed.

## Asset-specific scope and limitations

- Smooth untextured scalar concrete omits aggregate, pores, chips and manufacturing irregularity.
- Fragmented globally nonoverlapping per-triangle UV atlas is not seamless paint-ready.
- Standard FBX axis conversion leaves fresh-import matrix identity residual 8.742277657e-8, within established 1e-6 numerical export criterion; not byte-exact imported identity.
- FBX float 32 world evaluation introduces 29.8 nm side coordinate scatter; all local and exact Fraction-transformed intended planes remain analytically planar without tolerance; floor Z0 exact and actual rounded-world exact contact checks pass.
- Generic original static visual prop, not engineering-certified or exact branded replica.
