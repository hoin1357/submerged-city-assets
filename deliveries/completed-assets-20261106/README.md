# Completed original static props, 2026-11-06

This collection adds 61 completed asset sets, with 549 models in total. Every set contains three LODs in BLEND, FBX and GLB. Earlier published sets are not duplicated. Read each asset README before use.

These are original static visual props with embedded scalar PBR materials and no external texture dependencies. Reference photographs, PDFs, unfinished candidates, earlier revisions, supplemental pose snapshots and development reports are not included. No physical function, manufacturing accuracy, safety, universal importer behavior or Unity runtime certification is claimed. Fragmented triangle UV charts are not continuous paint-ready layouts.

Important disclosures include the contact-lens-case medical-use exclusion; the bicycle-bell polygon-bore dimensional allowance; the vacuum-flask tiny FBX grounding drift; the coin-purse normal-angle allowance; the tic-tac-toe sparse-pixel format-render differences; the luggage-rack nanometre-scale retopology and flat-normal import contract; and the cross memorial's unavailable earlier producer verification history. See the corresponding asset READMEs for exact details.

Reference-page attribution does not grant rights to third-party photographs, product branding or designs, and does not introduce a new model license. No reference media are bundled.

## Public-copy validation

Private authoring paths, unused embedded authoring text, and stale workflow labels were removed from these publication copies. The original source models were preserved. All 549 copies were reopened in Blender 4.3.2 and compared with the originals in the same format for geometry, topology, UVs, normals, hierarchy, transforms, materials, and applicable animation data. All comparisons passed. These checks do not certify other importers or target-engine behavior.

The SHA256_MANIFEST.json lists each model and README with its relative path, byte size, SHA-256 and Git blob identity; the manifest does not hash itself.
