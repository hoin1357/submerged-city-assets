# Submerged City Assets — 50 new object designs

This batch contains 50 distinct object designs. Each design has three LODs in Blender (.blend), FBX (.fbx), and glTF binary (.glb): nine model files per design, 450 model files total. `manifest.json` lists every model's relative path, byte size, and SHA-256 hash.

## Import and use notes

- Preserve authored normals. For GLB imports into Blender, use the explicit `NORMALS` shading path (for example, `import_shading="NORMALS"`). Default importer normal recomputation can change shading on some models. Stored GLB normals and explicit-normal imports were checked separately.
- Some multi-part assemblies contain intentional seated or overlapping component contacts. Treat individual parts separately; do not infer a globally intersection-free single solid from the assembled model.
- Where present, pivots, morphs, and translation controls are illustrative authoring controls. They are not certification of physical operation, biological rigging, electrical safety, cloth simulation, or Unity/game-engine behavior. Some objects are static props.
- LODs, file formats, and color/material regions are not additional designs. Hidden construction details may be reconstructed rather than exact manufacturer engineering.
