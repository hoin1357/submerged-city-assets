# Asset batch — 50 designs

450 standard three-LOD model files (BLEND/FBX/GLB), 6 original procedural PNG dependencies, and 27 supplemental illustrative Blender rigs. Rigs add zero designs and are not standard model files. This 50-design batch is prepared for publication; remote upload verification is a separate step.

## Preservation and limits

All source-copy geometry, UV, full numeric PBR, material settings and authored normals were freshly compared. All 150 GLBs are byte-identical. Actual source morph inventories are retained, with separate neutral/half/full key samples where present; mutually exclusive controls are not certified in arbitrary mixtures. Sleep-mask morphs remain LOD0-only. Other animal morph coverage is listed per model in the manifest. Supplemental rig hierarchy, actions, keyframes, interpolation and authored/midpoint evaluated poses remain editable and exact. Supplemental rig animation is BLEND-only and is not supplied as animated FBX/GLB; embedded standard-model morphs are listed separately. No animation is silently flattened. The dolphin, manatee and humpback whale supplementals are manual relative-shape-key supports with no actions or autoplay; five actual evaluated states are listed for each, with opposite key zero only as a sampling condition, not enforced exclusion. Untested mixtures are not certified.

Use explicit NORMALS GLB import in Blender to preserve authored normals. Original default-import recomputation failures remain separate diagnostics. Original cross-format deformation tolerances are distinct from exact sanitized source-copy identity. Intentional mechanical/organic contacts and combined strict failures remain; closed components do not mean an intersection-free whole assembly. Original fixed-grid failures and bounded exact-dyadic successes are recorded separately below, without rounding or invented failures. No arbitrary-angle, continuous collision, general solid containment, physical/load/medical/food-safety, manufacturing or Unity certification is added.

The baguette retains original embedded PNG bytes, decoded pixels, color space, alpha mode, samplers and bindings. Its unused linked Base Color fallback differs between original formats; each copy retains its own original values. Blender may discard unused zero-user orphan materials; every mesh-bound material, numeric shader input and rendering setting remains exactly preserved.
