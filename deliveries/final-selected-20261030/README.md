# Final 3D assets

133 assets; 1197 model files. Each asset has LOD0, LOD1 and LOD2 in BLEND, FBX and GLB formats.

Models are unpacked under `models/<asset ID>/lod<level>/`. See `catalog.txt` for names and `manifest.json` for relative paths, exact byte sizes and SHA-256 hashes. Only the selected final version of each included asset is present.

These are stylized static models, not engineering, anatomical, animation or engine certification assets. UV layouts may overlap and are not guaranteed lightmap-ready. Reconstructed assets are not claimed to be byte-identical restorations of historical files.

Machine-specific metadata paths have been redacted in the publication copies without altering geometry or other content. Manifest hashes describe these publication copies.
